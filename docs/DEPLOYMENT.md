# 영차 공개 준비 (2026-10-14)

아직 공개 주소는 없습니다. 아래 파일은 공개용 설정이며, 파일을 만드는 것만으로 서버가 생성되거나 결제가 발생하지 않습니다.

## 준비한 구성

Render의 웹 서버 하나와 1GB 영구 저장 공간을 사용하도록 `render.yaml`을 작성했습니다. 웹 화면과 자동 취소 작업을 같은 서버에서 별도 프로세스로 실행합니다. 프로세스가 종료되면 Supervisor가 다시 실행합니다. 로그인 방식과 SQLite DB 구성은 유지합니다.

무료 절전 서버는 브라우저 없이 5분 자동 취소를 실행한다는 조건에 맞지 않아 선택하지 않았습니다. **현재 요금은 미확인**입니다. Render 결제 화면의 서버·디스크 요금 및 백업 비용을 확인하고 발주자 승인을 받은 다음 생성해야 합니다. 인스턴스는 하나만 사용하며 디스크 사용 시 무중단 배포가 제한됩니다. 배포 중 잠시 접속·작업이 중단될 수 있습니다.

## 발주자가 해야 하는 일

1. 휴대폰 브라우저에서 Render 계정을 만들고 GitHub 저장소 접근을 연결합니다.
2. Blueprint로 이 저장소의 `render.yaml`을 선택합니다. 서버 생성·결제 확정 전에 표시되는 월 요금을 확인합니다.
3. 비용 승인 후 서버를 만듭니다. 성공하면 Render가 HTTPS 주소를 발급합니다. 별도 도메인 구매는 첫 공개에 필요하지 않습니다.
4. 그 주소를 카카오 Developers의 사이트 주소로 사용합니다. 로그인 callback은 `https://발급주소/accounts/kakao/login/callback/`입니다.
5. 카카오 설정값은 호스팅 보안 설정에 입력합니다. 비밀키나 비밀번호를 채팅에 보내지 않습니다.

로그인 연결·실제 기기 시험·운영 정책 확인 전에는 실제 주문 서비스를 시작하지 않습니다. `POLICIES_APPROVED=0`으로 신규 주문 관련 처리를 막고, 홈페이지와 로그인 준비 화면은 확인할 수 있게 했습니다. 영업시간·방 폐기·개인정보 보관 정책은 별도로 확정해야 합니다.

## 개발자 실행·관리

`docker build -t youngcha .`로 빌드합니다. 운영 환경에는 `DJANGO_SECRET_KEY`, `DJANGO_ALLOWED_HOSTS` 또는 Render의 `RENDER_EXTERNAL_HOSTNAME`이 필요합니다. DB 경로는 `/var/data/coffee.sqlite3`이며 `/var/data`를 영구 디스크로 연결해야 합니다. `.local`, `.env`, 개발 DB와 시연 계정은 이미지에 포함하지 않습니다. 운영 시작 시 마이그레이션만 실행하며 시연 자료는 만들지 않습니다.

부팅 초기 디스크 권한 설정만 root로 실행하고, 웹·마이그레이션·자동 취소는 UID 10001로 실행합니다. 상태 확인 주소 `/healthz`는 실제 주문 테이블과 자동 취소 작업의 최근 동작을 함께 검사합니다. 작업 동작 기록이 15초 넘게 오래되면 503을 반환합니다. 건강 상태 검사는 복구 보장이 아니므로 호스팅 장애 모니터링이 필요합니다.

최초 운영자는 호스팅의 보안 터미널에서 앱 사용자로 `python manage.py create_operator`를 실행해 생성합니다. 기본 운영 비밀번호는 없습니다. 백업·복원은 [운영 절차](OPERATIONS.md)를 따릅니다. 배포 전 백업하고 복구 시 서버와 작업을 모두 정지한 다음 DB를 복원합니다. 배포 버전 복구만으로 DB 마이그레이션이 되돌아가지는 않습니다.

## 실행 확인

- Django 자동 시험: 42개 통과. 권한·동시 요청·금액·기한·자동 취소 작업 상태 확인 포함.
- 운영 컨테이너: 홈페이지 및 상태 확인 HTTP 200, 작업 서버가 만료 주문 자동 취소·이력 한 건 저장, 컨테이너 재시작 후 주문·이력 유지 확인.
- 운영 보안 검사: 하위 도메인 전체 HSTS와 브라우저 preload 관련 경고 2개. 대표 도메인 미정이므로 임의로 켜지 않았습니다.
- 이 환경의 Docker 빌드 네트워크에서 DNS 오류 발생. 동일하게 고정한 패키지를 호스트에서 TLS 검증을 유지해 다운로드한 뒤, 임시 빌드 파일의 오프라인 설치 방식으로 이미지 시험. 호스팅의 원본 Dockerfile 온라인 빌드는 미실행입니다.
- 실제 Render 배포·외부 HTTPS 프록시·카카오 로그인·휴대폰 알림은 미실행입니다.
