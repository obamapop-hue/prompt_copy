# 영차 사용법

첫 화면의 **주문하기**를 눌러 카페를 고르세요.

총무는 오른쪽 위 **로그인**으로 카카오톡 로그인 후 닉네임을 정합니다.
로그인하면 그 자리가 **내정보**로 바뀝니다.
내정보에서 카카오 계정·영차 닉네임과 **내 주문 내역**을 볼 수 있습니다.

총무가 주문방 링크를 친구들에게 보냅니다.
친구들은 로그인 없이 링크에서 음료와 이름을 입력합니다.
총무가 주문을 모아 마감하고 카페에 전송합니다.
카페가 준비를 마치면 매장에서 받고 결제합니다.

지금은 시험용 화면입니다. 실제 카카오 로그인은 아직 연결 전입니다.

자세한 원리는 [영차 구조와 작동 방식](HOW_IT_WORKS.md)에 쉬운 말로 정리했습니다.
